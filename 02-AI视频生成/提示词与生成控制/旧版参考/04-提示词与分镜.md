# 提示词与分镜

> 提示词不是越长越好。复杂提示词的价值在于约束明确、动作可执行、镜头信息不冲突，并且能通过测试逐步改进。

## 1. 提示词的通用结构

一个可维护的视频提示词通常可以分为：

1.  **主体**：画面中是谁 / 什么。
2.  **场景**：在哪里、什么时间、什么环境。
3.  **动作**：主体在镜头内具体做什么，按什么顺序发生。
4.  **镜头**：景别、机位、构图、运动方式。
5.  **视觉风格**：写实程度、材质、光线、色彩、质感。
6.  **时间与节奏**：动作何时开始、持续多久、如何结束。
7.  **声音**：环境音、对白或音乐（仅在工具支持时）。
8.  **连续性约束**：必须保持的角色、服装、道具和空间关系。
9.  **限制条件**：不希望出现的元素、画面缺陷或冲突。
10. **输出要求**：时长、比例、分辨率等参数（如由界面设置，则不必重复）。

不同模型对自然语言、标签、负面提示词和参考素材的处理方式不同。应以目标模型的官方指南为准。

## 3. 单镜头提示词模板（可复制）

``` text
生成一个【时长】秒的单镜头视频。

【主体】
{角色 / 物体的可见特征；只写与镜头相关的内容}

【场景】
{地点、时间、天气、空间层次和关键道具}

【动作与时间顺序】
- 开始：{镜头开始时主体的状态}
- 过程：{一个主要动作，以及可见的动作变化}
- 结束：{镜头结束时主体的位置、姿态或状态}

【摄影机】
- 景别：{远景 / 全景 / 中景 / 近景 / 特写}
- 机位：{平视 / 低机位 / 高机位 / 俯拍 / 仰拍}
- 构图：{主体位置、前景与背景关系}
- 运镜：{固定 / 缓慢推进 / 后退 / 横移 / 跟拍 / 轻微摇镜}
- 焦点：{需要突出什么；避免不必要的焦点变化}

【视觉风格】
{写实程度、材质、色彩、光线方向、氛围和画面质感}

【声音】
{环境音 / 对白 / 音乐；若模型不可靠，留给后期制作}

【连续性约束】
{角色外貌、服装、道具、空间布局等必须保持的内容}

【限制】
避免出现与剧情冲突的额外人物、无关文字、意外换装、主体变形、无意义的镜头抖动。
```

## 4. 负面提示词怎么用

负面提示词不是通用魔法词表。部分模型有独立的 Negative Prompt
字段，部分模型主要依赖正向描述、参考图和参数；有些模型可能忽略或误解冗长的否定描述。

优先级建议： 1. 在正向提示词中明确"应该出现什么"。 2.
用简短限制描述最重要的错误类型。 3.
如果平台提供独立负面提示词字段，再放入与该模型兼容的约束。 4.
每次只调整少量条件，并比较结果。

示例（仅用于支持负面提示词的工具，需实测）：

``` text
Negative prompt:
unintended text, watermark, duplicated person, distorted hands, inconsistent clothing, abrupt camera shake, flickering background
```

注意：不能保证所有模型都理解这些英文词，也不能保证加上负面提示词一定改善效果。

## 5. 电影感镜头提示词：更精细的写法

复杂提示词应当明确动作和摄影机如何配合，而不是堆叠"8K、电影感、史诗级、极致细节"等形容词。

``` text
单镜头，时长 5 秒，写实悬疑电影风格。

场景：深夜，老旧气象站的地下机房。冷白色顶灯间歇闪烁，潮湿的水泥墙面有细微反光。画面后方是一扇半开的金属门，门外走廊几乎完全黑暗。

主体：一名穿深色工作外套的年轻守夜人，短黑发，右手握着小型手电筒。保持角色的脸部、发型、服装和手电筒外观稳定。

动作：
0–1 秒：人物停在控制台旁，身体保持静止，只用眼睛看向半开的门。
1–3 秒：人物缓慢转头，手电筒光束随手腕移动，扫过门框和走廊地面。
3–5 秒：光束停住，门外远处出现一个模糊的人形影子，但人物没有立刻追过去。

摄影机：中近景，略低于人物眼睛的机位，摄影机非常缓慢地向前推进；保持空间方向稳定，不切镜，不突然变焦。人物位于画面左侧，门位于右侧背景。

光线与质感：冷色低照度，局部硬光，轻微胶片颗粒，暗部保留细节，真实材质和自然动作。

声音：持续低沉的通风设备声，灯具轻微电流声，手电筒开关声；不添加音乐和对白。

约束：单一连续镜头，不改变人物服装，不新增清晰可辨的其他角色，不改变房间布局，不出现字幕或水印。动作应克制、缓慢、可观察。
```

这是一个可用于试验的提示词草案，不是保证生成结果的"万能提示词"。先用短时长和低成本测试，再决定是否进行高分辨率生成。

## 6. 分镜生成提示词（可复制）

``` text
你是 AI 视频项目的分镜导演。请把下面的故事拆解为适合 AI 视频生成和后期剪辑的镜头表。

作品参数：
- 类型：{填写}
- 目标时长：{填写}
- 画面比例：{填写}
- 视觉风格：{填写}
- 主要工具 / 模型：{填写；不确定时写“待选择”}
- 是否需要对白：{是 / 否}
- 角色一致性要求：{填写}

故事：
{粘贴故事}

规则：
1. 不改变故事的核心事件和人物动机；新增情节必须标注为建议。
2. 每个镜头只安排一个主要动作，避免同时出现多个复杂事件。
3. 每个镜头写清楚时长、景别、机位、构图、主体动作、运镜、光线、声音和连续性约束。
4. 明确镜头之间人物的位置、视线方向、道具状态和空间关系。
5. 如果某个镜头很难生成，提出更稳妥的替代方案，例如拆镜、静态关键帧、画外音或后期音效。
6. 不要默认所有镜头都必须用文生视频；可以选择图生视频、参考图、首尾帧或后期剪辑。
7. 总时长应接近目标时长，并说明时长分配理由。
8. 不确定的模型能力标注“待验证”，不要假装已经测试过。

先输出镜头表，再输出：
A. 角色资产清单
B. 场景资产清单
C. 道具清单
D. 高风险镜头及替代方案
E. 生成顺序与验收标准
```

## 7. 生成结果评价表

每个镜头按 1--5 分记录，分数是自己的评估，不是模型客观指标。

  维度       检查问题
  ---------- ----------------------------------
  主体准确   角色 / 物体是否符合设定？
  动作完成   动作是否发生、顺序是否正确？
  镜头符合   景别、构图、运镜是否接近目标？
  连续性     服装、道具、空间是否稳定？
  画面质量   是否存在明显变形、闪烁或伪影？
  情绪表达   是否传达预期情绪？
  可剪辑性   开头和结尾是否方便接入其他镜头？
  成本效率   是否值得保留，是否需要重生成？

## 8. 提示词版本记录

每次调整只改变少量因素，并保存： - 原始提示词； - 修改版提示词； -
模型与版本； - 参考素材； - 参数与生成时间； - 结果文件； -
哪个维度变好、哪个变差； - 下一次准备改什么。

这比不断追加形容词更容易形成真正可复用的经验。

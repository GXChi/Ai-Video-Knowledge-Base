# 自制教程

> 这里记录自己真正制作、验证后准备发布的教程。它与"教程收藏"分开：收藏是学习材料，自制教程是自己的整理、实验和讲解成果。

## 1. 教程分类

-   入门：用一个工具完成一项具体任务。
-   端到端：从创意到成片的完整流程。
-   提示词：解释复杂提示词如何设计、怎么调整、什么情况下失效。
-   工具实操：安装、配置、参数、常见错误。
-   工作流：画布 / 节点 / API / 自动化。
-   复盘：对比多个方案、失败案例与改进。
-   项目教程：从空目录开始完成一项作品。

## 2. 自制教程的标准结构

``` markdown
# 教程标题

## 这篇教程要完成什么
用一句话描述最终成果。尽量有明确的可见输出。

## 适用人群与前置条件
- 需要什么账号 / 工具 / 硬件：
- 预计时间：
- 费用或积分消耗：
- 不适合什么情况：

## 最终效果
放成片、截图或结果说明；注明是否为本人实测。

## 使用工具与版本
- 工具：
- 模型 / 版本：
- 日期：
- 官方文档：

## 准备材料
列出输入素材、提示词、文件和配置。

## 操作步骤
每一步写清：
1. 做什么；
2. 输入什么；
3. 预期看到什么；
4. 如果结果不同如何排查。

## 可复制资产
- 完整提示词：
- 参数：
- 工作流文件：
- Skill：
- 参考素材：

## 常见问题
记录真实遇到的问题，不凭空编造“已解决”。

## 验收标准
列出读者如何判断自己是否完成。

## 结果与局限
- 哪些情况成功：
- 哪些情况失败：
- 结果是否可重复：
- 已知限制：

## 来源与授权
记录素材来源、参考教程、引用内容和使用权利。

## 复盘
下次会改什么？哪些内容值得沉淀成独立提示词或 Skill？
```

## 3. 教程发布前检查

-   [ ] 标题描述具体结果，而不是只有"保姆级教程"。
-   [ ] 工具、模型和日期明确。
-   [ ] 关键步骤经过本人实际验证，或明确标注为理论整理。
-   [ ] 复制的提示词没有遗漏必要变量。
-   [ ] 截图、素材、音乐和示例有合理使用权限。
-   [ ] 费用、失败扣费和限制没有用过时信息冒充当前事实。
-   [ ] 读者能知道成功的标准。
-   [ ] 已说明哪些部分存在随机性，不能保证完全复现。

## 4. 推荐的第一批自制教程

1.  **我的第一支 AI 短片：从一句创意到成片**。
2.  **如何把一个故事拆成 AI 视频分镜**。
3.  **如何写一个可复用的单镜头视频提示词**。
4.  **如何建立角色参考图，减少人物外貌变化**。
5.  **如何用多个生成结果筛选更好的镜头**。
6.  **如何把生成的视频剪辑成完整短片**。
7.  **如何记录提示词版本和生成失败原因**。

先做第一篇就够了。后续教程最好来自实际操作中遇到的问题。

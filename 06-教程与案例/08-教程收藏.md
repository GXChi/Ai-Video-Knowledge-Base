## 2. 初步可用的官方教程入口

以下是本次检索到的官方或厂商技术资料，适合作为起点。它们不一定都是面向零基础的完整视频课程，部分是文档或工作流指南。

## 3. 如何找大众与小众教程

搜索时不要只搜"AI 视频教程"，建议按任务搜索：

-   `AI 视频 分镜 提示词 实战`
-   `AI 短剧 从剧本到成片 工作流`
-   `ComfyUI 视频工作流 教程`
-   `ComfyUI 视频 首尾帧 工作流`
-   `AI 视频 角色一致性 参考图`
-   `AI 视频 镜头语言 运镜 提示词`
-   `Seedance / 可灵 / 即梦 当前版本 提示词教程`
-   `AI 视频 API 自动化 Python`
-   `AI 视频生成 失败案例 复盘`
-   `AI 视频 后期剪辑 音效 节奏`

可以在 B 站、YouTube、官方文档站、GitHub
和创作者社区分别搜索。小众教程可能有更细的节点和参数，但要额外确认作者使用的版本、模型、插件和权限。

## 4. 教程筛选标准

优先收藏： - 展示完整输入、提示词和参数的教程； -
有原始工作流或项目文件可供检查； -
解释为什么这么做，而不是只展示结果； - 有失败案例和排查过程； -
标明工具版本与日期； - 允许读者判断结果是否可复现。

谨慎看待： - 只展示最佳结果，却不提供提示词和参数； -
夸张承诺"一键出商业级短剧"； - 把会员积分、API
成本和本地部署成本混为一谈； -
不说明使用的内测功能、特殊账号或第三方中转服务； -
没有授权说明，却直接使用完整小说、影视片段或他人素材。

## 5. 注意：收藏不等于照搬

可以学习别人公开的流程、比较不同方案并记录自己的理解。若要把别人的提示词、脚本、工作流或素材直接发布到自己的知识库，需要检查许可、署名与再分发条件。更好的长期资产是：记录来源，理解原理，自己验证，再写出有明确增量的整理和教程。

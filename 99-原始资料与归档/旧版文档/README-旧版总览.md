# AI 视频创作知识库

> 面向个人学习、内容创作与 AI
> 工作流的可复用知识资产库。目标不仅是"记录看过什么"，而是逐步沉淀出能被人直接使用、也能被
> AI / Agent 检索和执行的创作方案。

## 这个知识库解决什么问题

1.  **学习**：理解 AI 视频创作从创意到成片的完整链路。
2.  **选型**：按任务、预算、控制程度和自动化需求选择工具。
3.  **复用**：保存复杂提示词、分镜模板、角色/场景设定和工作流。
4.  **实操**：用可执行的方案做出样片，并记录失败原因与改进。
5.  **AI 调用**：让未来的 Agent
    能检索工具说明、输入输出约定、提示词与流程，而不是每次从零推理。

## 重要约定：不要混淆三种状态

-   **待验证**：来自视频、文章、社区分享或 AI 建议，尚未亲自验证。
-   **已验证**：记录了模型/版本、工具、关键参数、输入素材和结果。
-   **可复用**：至少在明确的条件下成功复现，并说明限制、失败模式和修改方法。

不要把"教程里演示成功"直接写成"稳定有效"。AI
视频生成具有随机性，模型版本、参考素材、提示词、参数和平台策略变化都会影响结果。

## 建议的资产类型

-   **知识文章**：解释原理、概念、方法和选择依据。
-   **工具卡片**：一个工具一份记录，避免工具变化时修改所有教程。
-   **提示词资产**：可直接复制的完整提示词，附变量说明和适用条件。
-   **工作流方案**：输入、步骤、工具、输出、人工检查点和失败回退。
-   **Skill / Agent 资产**：供 AI
    按明确步骤执行的指令、工具约定和验收标准。
-   **教程**：讲清楚为什么这么做，并带读者完成一个结果。
-   **实战记录**：真实生成结果、成本、耗时、问题和改进。

## 资产命名建议

-   知识文章：`概念-主题.md`
-   工具：`工具-名称.md`
-   提示词：`提示词-任务-版本.md`
-   工作流：`工作流-目标-版本.md`
-   Skill：`skill-动作名称/`
-   实战：`实战-日期-项目名.md`

例如：`提示词-悬疑短片分镜生成-v1.md`、`工作流-小说到首支样片-v1.md`。

## 目前最小可行的起步方式

第一阶段只做三件事：

1.  记录工具和教程，先把信息来源收集起来。
2.  选一个 15--30 秒的简单故事，完成第一支样片。
3.  把实际使用过的提示词和流程整理成可复用资产。

先形成闭环，再扩充知识库；不需要一开始就把所有目录填满。

# AI 视频创作知识库

这是用于学习、查阅和积累故事创作、影视表达与 AI 视频制作知识的个人知识库。文档既供人阅读，也可作为 AI 创作任务的参考；收录不等于已经复核，文档存在不等于学习掌握。

## 从这里开始

1. 当前先读[故事是什么](01-影视创作基础/01-故事创作/01-故事基础/01-故事是什么.md)。
2. 再读完整案例[演示还没结束](01-影视创作基础/01-故事创作/案例/演示还没结束.md)，正文之后有分析。
3. 想了解类型、单元故事等，读[分类与表现形式](01-影视创作基础/01-故事创作/01-故事基础/02-故事的分类与表现形式.md)。
4. 故事基础六篇、创意与主题三篇的完整阅读入口，见[故事创作知识地图](01-影视创作基础/01-故事创作/00-故事创作知识地图.md)。每篇附目录与关联阅读。
5. 想了解八步等工具，可看[结构与创作方法导览](01-影视创作基础/01-故事创作/05-结构与创作方法/00-结构与创作方法导览.md)；其中 05 是主题编号，不是故事基础的第五课。

以阅读 Markdown 为主，聊天用于语音或文字答疑、反馈和修订。可以先保存有完整脉络的草稿，再根据阅读反馈完善。不必每段讲解后做题，也不按文件编号逐项闯关。

## 维护原则

- 先查已有内容，基础介绍要能独立读懂；地图负责导航，正文负责解释。
- 术语先介绍再比较；理论配完整案例，短例句不必单建文件。
- 类型、表达形式、结构方法与制作流程分清，不把一种方法说成唯一标准。
- 按实际内容拆文件与目录，不为目录齐全批量建立空文章。
- 工具信息、方法版本和不确定事项写明来源与状态。
- 文档草稿、读者认可、理解与实践分别记录。
- 当前未学习的部分保留为后续方向，不因路线存在就擅自推进。

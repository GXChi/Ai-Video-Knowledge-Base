# 角色与场景资产

> 角色和场景资产的目标，是减少每个镜头都重新发明人物外貌和环境的情况。它们是视觉参考，不保证所有模型自动保持完全一致。

## 2. 角色参考图提示词

``` text
为原创角色【角色名】制作一张角色设定参考图，供后续多镜头 AI 视频制作使用。

角色设定：
{粘贴已确定的外貌、年龄段、体型、发型、服装、配色和识别特征}

画面要求：
- 同一角色，外貌特征明确且容易识别。
- 展示正面、侧面、背面或全身设定；如果工具不擅长多视图，则分别生成并人工筛选。
- 服装结构、颜色、材质和关键配饰清晰。
- 中性、清楚的照明，避免过度戏剧化的光线遮挡细节。
- 背景简洁，不添加与角色设定冲突的道具。
- 视觉风格：{写实电影 / 动漫 / 3D 动画 / 其他}
- 不要加入文字、水印、额外人物或未经设定的配饰。

请优先保持设定准确，不要自行添加新的角色背景或改变服装设计。
```

## 4. 场景概念图提示词

``` text
为短片【作品名】设计场景【场景名】的视觉参考图。

场景信息：
{粘贴时代、地点、空间结构、固定道具、天气和氛围}

构图要求：
- 清晰展示空间关系，能够辨认入口、出口和主要区域。
- 前景、中景、背景有明确层次。
- 主要道具的位置与尺寸关系合理。
- 光线方向、色温和主色调明确。
- 画面风格与作品整体视觉设定一致：{填写}
- 画面中不出现未经设定的人物或文字。
- 避免无意义的装饰细节遮挡关键空间信息。

输出优先用于分镜规划，而不只是单张漂亮概念画。
```

## 5. 资产命名与版本

建议采用稳定 ID，而不是只用自然语言标题：

-   角色：`CHAR-001-主角名`
-   场景：`LOC-001-场景名`
-   道具：`PROP-001-道具名`
-   参考图：`CHAR-001-front-v02.png`
-   视频镜头：`SHOT-001-v03.mp4`

每次修改要记录变化原因。不要覆盖已经用于成片的旧版本，否则后续很难判断画面差异来自提示词、素材还是模型更新。

## 6. 一致性检查

每次生成后比较： - 脸型、发型、年龄感是否变化； -
服装、配色、配饰是否变化； - 关键道具是否丢失或变形； -
场景的入口、窗户、家具等空间关系是否变化； -
光线方向和色调是否与相邻镜头冲突； - 动作是否符合人物设定。

## 7. 失败时的处理顺序

1.  检查提示词是否互相矛盾。
2.  检查参考图是否清晰且确实包含要保持的特征。
3.  减少单镜头中同时发生的动作。
4.  尝试固定构图或使用首帧 / 参考图模式。
5.  先生成静态关键帧，再让视频模型生成运动。
6.  通过剪辑切换镜头，避免强求一个镜头完成所有变化。
7.  记录模型版本、素材和参数；不要只写"模型不行"。

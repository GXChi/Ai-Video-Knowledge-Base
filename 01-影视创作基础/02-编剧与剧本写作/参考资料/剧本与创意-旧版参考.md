# 剧本与创意

> 目标：让创意可以被拆成可生成、可剪辑、可验证的镜头，而不是只停留在一个故事点子。

## 1. 先决定作品形态

  --------------------------------------------------------------------------------------------------------------------
  形态              典型特点                         适合的起步方式                         主要难点
  ----------------- -------------------------------- -------------------------------------- --------------------------
  电影感短片        视觉、氛围、少量对白             一个场景、一个核心动作、一个情绪转折   镜头衔接、视觉一致性

  真人感短剧        人物关系、对白、冲突、悬念       一段冲突明确的短场景                   人脸一致、口型、多人互动

  动态漫 / 漫剧     角色设定、画面分层、旁白和对白   先做角色与关键画面，再做轻运动         角色一致、镜头重复感

  动画 / 奇幻短片   视觉设定、动作、世界观           先建立风格和角色参考图                 动作复杂度、风格稳定

  悬疑 / 恐怖短片   信息控制、声音、反转、氛围       用视线、声音和画外空间制造未知         不能只靠血腥或突然惊吓

  知识解说 /        旁白主导、画面辅助               先写旁白，再为每段设计画面             画面与信息对应、节奏
  故事讲述                                                                                  
  --------------------------------------------------------------------------------------------------------------------

题材可以是玄幻、修仙、悬疑、恐怖、历史、科幻、末世、神话、民俗怪谈等。题材不是固定模板；同一题材可以做成真人短剧、动态漫或电影感短片。

## 2. 一句话创意模板

``` text
在【时间 / 地点 / 世界规则】下，【主角】为了【明确目标】必须面对【阻碍】；
当【意外事件】发生后，主角发现【新的信息 / 代价】，最终不得不【选择或行动】。
作品的核心情绪是【情绪】，结尾留下【结果 / 悬念 / 余味】。
```

例子：

> 暴雨夜，一名负责看守废弃气象站的年轻人，为了确认反复出现的求救信号进入地下机房，却发现信号来自明天的自己；每次回应都会让站内的时间更接近停止。

这只是创意示例，不是已经验证的成片方案。

## 3. 30 秒短片的结构参考

-   **0--3 秒：钩子**。先展示异常画面、危险信号、强烈问题或反常行为。
-   **3--8 秒：建立情境**。观众需要知道人物在哪里、正在做什么。
-   **8--18 秒：升级**。出现新的阻碍、线索或变化。
-   **18--25 秒：转折 / 选择**。让人物采取行动，改变局面。
-   **25--30 秒：结果 / 悬念**。给出一个有意义的结果，或留下清晰的问题。

这是便于练习的节奏参考，不是所有短片都必须遵循的规则。安静的氛围短片可能更慢，喜剧可能更快。

## 4. 把故事改成可生成的镜头

生成模型通常更容易处理**单一、可见、短时段的动作**，而不是一段抽象心理或包含多个连续事件的长段描述。

把"他意识到自己被监视，感到恐惧，决定逃走"拆成：

1.  中近景：人物停止动作，听见身后细微声响。
2.  特写：人物的眼睛缓慢转向门缝。
3.  主观镜头：走廊尽头的灯轻轻闪烁，门外没有人。
4.  近景：人物缓慢后退，手指紧握门把。
5.  低机位：门外影子从画面边缘掠过。

拆镜头时检查： - 每个镜头是否只有一个主要动作？ -
人物的动作是否能被画面直接表达？ - 镜头时长是否适合动作完成？ -
观众是否能理解空间关系？ - 上一个镜头的动作能否自然接到下一个镜头？ -
哪些信息应该通过音效、旁白或剪辑表达，而不是强迫模型一次生成？

## 5. 小说改编与版权

可以先从原创故事或明确获得授权的文本开始。对网络小说、付费内容、影视剧本和他人视频，不要默认"网上能看到"就代表可以改编或商用。记录来源、作者、授权范围、允许的平台、署名要求和期限。

改编时不要机械地逐句转成镜头。先抽取： - 主角目标； - 主要冲突； -
人物关系； - 世界规则； - 关键道具； - 视觉奇观； - 重要转折； -
必须保留的情节； - 可以合并或删减的内容。

对于长篇小说，优先选择一个独立、冲突明确的场景作为试验，而不是一开始就改编整部作品。

## 6. 剧本分析提示词（可复制，待验证）

``` text
你是一名熟悉短片叙事、镜头表达和 AI 视频制作限制的编剧与分镜策划。

请分析我提供的故事，并为后续 AI 视频制作做准备。不要直接扩写成很长的小说。

【作品目标】
- 作品形态：{电影感短片 / 真人短剧 / 动态漫 / 动画 / 解说}
- 目标时长：{例如 30 秒}
- 画面比例：{9:16 / 16:9 / 1:1}
- 题材与风格：{填写}
- 目标观众：{填写}
- 视觉预算或制作限制：{填写}

【故事原文 / 创意】
{粘贴故事}

请按顺序输出：
1. 一句话概括故事。
2. 主角目标、阻碍、风险、情绪变化。
3. 观众必须知道的信息，以及可以隐藏的信息。
4. 最有视觉表现力的 3 个瞬间。
5. 最适合开头的钩子，以及理由。
6. 建议的节奏结构。
7. 需要固定的角色、场景、道具和世界规则。
8. 将故事拆成镜头的建议；每个镜头只安排一个主要动作。
9. 可能难以通过 AI 视频稳定生成的内容，并给出替代方案。
10. 版权或素材来源方面需要确认的事项。

不要虚构原文中不存在的关键设定。对不确定的内容标注“建议”或“待确认”。
```

## 7. 创意质量检查表

-   [ ] 能否用一句话说清主角想做什么？
-   [ ] 是否存在清楚的冲突或问题？
-   [ ] 开头几秒是否有值得继续看的信息？
-   [ ] 结尾是否有结果、转折、情绪落点或悬念？
-   [ ] 关键情节是否能通过画面表达？
-   [ ] 场景数量是否与预算和工具能力匹配？
-   [ ] 是否存在难以生成的多人复杂互动？
-   [ ] 是否有角色、道具或空间连续性风险？
-   [ ] 素材来源与改编权利是否清楚？

## 8. 后续可继续沉淀的专题

-   玄幻 / 修仙短片如何设计视觉奇观；
-   悬疑片如何用信息差和画外空间制造紧张；
-   恐怖片的镜头、音效与节奏；
-   历史题材的服装、建筑、道具考据；
-   小说选段的筛选与短片化；
-   对白场景如何拆分为适合生成的镜头；
-   如何控制 15 秒、30 秒、60 秒短片的叙事密度。
